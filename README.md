# BlueChat 🔵
Bluetooth Messaging App — Web Option A
CNDC BSCS-6B | SZABIST-ISB

## Kaise Chalayein
1. index.html Chrome mein kholo
2. "Scan for Devices" dabao
3. Device select karo aur connect karo

## Requirements
- Google Chrome ya Microsoft Edge browser
- Android phone ya Windows/Mac PC
- iOS (iPhone) pe kaam NAHI karta

## Features
- Bluetooth device scan aur connect
- Text messaging (sent=right, received=left)
- File transfer with progress bar
- Message timestamps
- Delivery receipts (double tick)
- Demo Mode (bina real device ke bhi test kar sako)

## Run karne ka tarika
VS Code mein Live Server extension se:
1. index.html pe right-click
2. "Open with Live Server" dabao
3. Chrome mein khul jaayega
